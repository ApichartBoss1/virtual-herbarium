# รายงานผลการทดสอบระบบ Virtual Herbarium

- วันที่ทดสอบ: 31 ตุลาคม 2569
- โค้ดที่ทดสอบ: branch `fix-label-coordinates` commit `dcc99aa`
- สภาพแวดล้อม: macOS, Node.js 22, Next.js 16 production build (`next start`), Google Chrome headless
- ข้อมูล: ฐานข้อมูล Supabase จริง อ่านอย่างเดียวด้วย anon key

## วิธีทดสอบ

- **ไม่มีการเขียนข้อมูลลงฐานข้อมูลจริง:** คำขอเขียนทั้งหมดถูกดักและตอบด้วยค่าจำลอง ได้แก่ insert, update, delete, Storage upload/remove, Nominatim และ Open-Meteo
  - หลังทดสอบ ฐานข้อมูลยังมี 57 รายการเท่าเดิม
  - รายการที่ทดสอบแก้ไขยังมีค่าเดิม
- **ข้อยกเว้น:** การทดสอบ RLS (S03) ส่งคำขอจริงด้วย anon key ตามที่กำหนด และถูกปฏิเสธทุกคำขอ
- **หน้า admin:** ใช้การล็อกอินจำลอง (session ของ admin ใน localStorage) การอ่านข้อมูลส่งด้วย anon key
- **การรอหน้าเว็บ:** ทุกคำสั่งมี timeout ไม่รอ network idle แต่รอ selector ที่กำหนดพร้อมเวลาสูงสุด

## ส่วนที่ 3: ประสิทธิภาพ

### 3.1 เวลาจนข้อมูลหลักขึ้น

วัดจาก production build บนเครื่องที่ทดสอบ โดยปิด cache ของเบราว์เซอร์และโหลดแต่ละหน้าใหม่

- **Slow 3G:** ตั้งตามค่าของ Chrome DevTools คือ latency 2,000 ms และความเร็ว 50,000 byte/วินาที
- **มือถือ:** หน้าจอ 390 × 844 px
- **เกณฑ์ "ข้อมูลหลักขึ้น" ของแต่ละหน้า:**
  - `/`: หัวข้อหลักแสดง
  - `/plants`: การ์ดที่ลิงก์ไปรายการจริงแสดง
  - `/plants/[id]`: ข้อมูลระเบียนและ PNU แสดง
  - `/map`: หมุดบนแผนที่พร้อม

| หน้า | เดสก์ท็อป ปกติ | เดสก์ท็อป Slow 3G | มือถือ ปกติ | มือถือ Slow 3G |
|---|---|---|---|---|
| `/` | 0.08 วินาที | 5.8 วินาที | 0.09 วินาที | 5.7 วินาที |

- **First Contentful Paint บนเครือข่ายปกติ:** ทุกหน้าอยู่ที่ 0.05–0.10 วินาที
- **First Contentful Paint บน Slow 3G:** 5.4–7.4 วินาที ยกเว้นหน้ารายละเอียดบนเดสก์ท็อปที่ 13.8 วินาที
